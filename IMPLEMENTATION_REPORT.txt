                           FEATURE DETAILS
═══════════════════════════════════════════════════════════════════════════

SPEECH LEARNING:
- Sentences: 10 practice sentences
- TTS: Android TextToSpeech API
- Recognition: Android SpeechRecognizer API
- Evaluation: Levenshtein distance algorithm
- Feedback levels: 4 (Excellent, Good, Needs Improvement, Try Again)

VISUAL LEARNING:
- Words: 10 vocabulary words
- Each word includes:
  * English word
  * Arabic translation
  * Phonetic pronunciation (IPA)
  * Example sentence
  * Image placeholder
- Progress tracking with visual bar
- Mark as learned functionality

INTERACTIVE CHAT:
- Chat UI: RecyclerView with custom adapter
- Message types: User (blue) and Bot (white)
- Grammar rules checked:
  * Capitalization (sentence start, "I")
  * Punctuation (sentence end)
  * Contractions (30+ patterns)
- Feedback: Detailed error explanations in Arabic

GRAMMAR CHECKER:
- Error types: 5 (Capitalization, Punctuation, Contraction, Spelling, Grammar)
- Contractions supported: 30+
  (don't, can't, won't, I'm, you're, etc.)
- Similarity algorithm: Levenshtein distance
- Performance: O(n*m) time complexity
